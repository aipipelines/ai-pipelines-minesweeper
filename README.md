# Minesweeper React App

A simple frontend-only Minesweeper game built with React.

## Features

- No authentication or registration
- All game logic runs in the browser
- New game starts on every page load or "New Game" button click
- Beginner board: 9x9 grid, 10 mines
- Left click to reveal, right click to flag

## Usage

1. `npm install`
2. `npm start`
3. Open [http://localhost:3000](http://localhost:3000) in your browser
